# Шаблон технического задания на поток / витрину данных (продукт NET)

> Реконструированный шаблон. Используется ревьюером как «ожидаемая структура»:
> по нему проверяется покрытие разделов и полнота описания. Данные в примерах
> нейтральные — без реальных имён систем, полей и потоков.

## 1. Общая информация и статус
- Название потока / витрины, краткий код.
- Автор ТЗ, дата, версия, статус (черновик / на ревью / согласовано).
- Ссылки на связанные задачи и документы.
- Потребители витрины (кто и зачем использует результат).

## 2. Бизнес-контекст и цель
- Какую задачу закрывает поток, какое решение принимается по этим данным.
- Что именно является результатом (витрина, промежуточный слой, экспорт).
- Границы: что в скоуп не входит.

## 3. Глоссарий терминов и сокращений
- Расшифровка аббревиатур и доменных терминов.
- Ссылка на эталонные определения бизнес-показателей.

## 4. Источники данных
Для каждого источника:
- система-источник и слой (сырой слой / витрина другого продукта / внешний API);
- полное имя объекта (схема.таблица, топик, эндпоинт, шаблон имени файла);
- способ получения (SQL, выгрузка, стрим, файл) и параметры подключения;
- частота обновления источника и момент готовности данных;
- полный срез или дельта; поле версии / времени изменения;
- фильтр на стороне источника, если есть.

## 5. Целевой объект (структура, гранулярность)
- Схема и имя целевой таблицы.
- Гранулярность: что представляет одна строка.
- Структура: перечень полей с типами, обязательностью, описанием (или DDL).
- Первичный / бизнес-ключ.
- Партиционирование и срок хранения (retention).

## 6. Маппинг полей
Таблица: поле приёмника → источник (таблица.поле или формула), тип, обязательность,
правило заполнения, преобразование, комментарий.
- Явно указать поля с расчётом «по умолчанию», константы, технические поля
  (дата загрузки, идентификатор запуска).
- Явно указать поля источника, которые НЕ переносятся, и почему.

## 7. Логика трансформации и расчётов
- Порядок шагов обработки.
- Фильтрация: условия отбора строк (проверяемо, со значениями/справочниками).
- Соединения: таблицы, ключи, тип join, ожидаемая кардинальность, поведение
  при отсутствии и при множественном совпадении.
- Агрегации: группировки, оконные функции.
- Расчётные поля: формула через имена полей, округление, обработка деления на
  ноль и отсутствующих слагаемых.
- Граничные случаи и как они обрабатываются.

## 8. Историчность (SCD), обновления и удаления
- Тип историчности: снимок на дату / SCD1 (только актуальное) / SCD2 (история) / иное.
- Правила закрытия и открытия версий, поля периода действия.
- Обработка изменений «задним числом».
- Как отражается удаление записи в источнике (физическое и логическое).

## 9. Стратегия загрузки и инкремент
- Режим: полная перезагрузка / инкрементальная загрузка.
- Поле-водяной знак (watermark) и правило его продвижения.
- Окно перекрытия для опаздывающих данных.
- Идемпотентность: результат повторного запуска за тот же период.
- Перезаливка (reload) исторического периода: как запускается, кем, с какими эффектами.
- Зависимости по порядку загрузки с другими объектами.

## 10. Дедупликация
- Признак дубликата (набор полей).
- Правило выбора «золотой» записи из группы дубликатов.
- Этап, на котором выполняется дедупликация.

## 11. Обработка NULL и некорректных значений
- Поведение при NULL в обязательных полях; значения по умолчанию и заглушки.
- Обработка явно некорректных значений (отрицательные, будущие даты, вне справочника).
- Заглушки для несопоставленных ссылок на справочники.

## 12. Контроли качества данных
- Перечень проверок: объём, уникальность ключа, доля NULL, сверка сумм с источником,
  ссылочная целостность.
- Пороги срабатывания.
- Действие при нарушении: стоп загрузки / карантин / загрузка с оповещением.

## 13. Расписание, SLA и зависимости
- Частота и время запуска, вышестоящие зависимости.
- Дедлайн готовности витрины (SLA) и его потребитель.
- Поведение при недоступности или неполноте источника; политика повторов.

## 14. Объёмы и нагрузка
- Стартовый объём (строки / ГБ).
- Суточный и месячный прирост.
- Историческая глубина возможного пересчёта.
- Пиковые периоды.

## 15. Доступы, ПДн и безопасность
- Наличие персональных / чувствительных данных.
- Правила маскирования / хеширования отдельных полей.
- Роли доступа к витрине.
- Учётная запись и права для чтения источников.

## 16. Примеры данных
- Репрезентативные строки источника и соответствующий им результат в витрине.
- Обязательно нетривиальные случаи: NULL, дубликат, изменение задним числом.

## 17. Открытые вопросы
- Список нерешённых вопросов с ответственными и сроками.
