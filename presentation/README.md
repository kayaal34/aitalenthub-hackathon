# Презентации

| Файл | Назначение |
| --- | --- |
| `ТЗ-Ревьюер — промежуточная защита.pptx` | промежуточная защита, 8 слайдов |
| `build_intermediate_deck.js` | генератор промежуточной презентации (pptxgenjs) |

## Как пересобрать

```bash
npm install pptxgenjs
node build_intermediate_deck.js
# необязательный аргумент — путь к выходному файлу:
# node build_intermediate_deck.js "out.pptx"
```

Правки вносите в `.js` и пересобирайте — так презентация остаётся
воспроизводимой. Точечные правки текста можно делать и прямо в `.pptx`.
